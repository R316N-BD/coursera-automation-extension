# Security Policy

## Reporting a Vulnerability

We take the security of the Coursera Automation Extension seriously. If you have discovered a security vulnerability, we appreciate your help in disclosing it to us in a responsible manner.

### How to Report

**Please do NOT report security vulnerabilities through public GitHub issues.**

Instead, please report security vulnerabilities by:

1. **Email**: Send an email to the maintainer with details about the vulnerability
2. **Private Security Advisory**: Use GitHub's private vulnerability reporting feature

### What to Include

When reporting a vulnerability, please include:

- Type of vulnerability (e.g., XSS, SQL injection, etc.)
- Full paths of source file(s) related to the vulnerability
- The location of the affected source code (tag/branch/commit or direct URL)
- Step-by-step instructions to reproduce the issue
- Proof-of-concept or exploit code (if possible)
- Impact of the vulnerability
- Potential fixes (if you have suggestions)

### Response Timeline

- We will acknowledge receipt of your vulnerability report within 48 hours
- We will provide a detailed response within 7 days
- We will work on a fix and keep you updated on the progress
- Once the vulnerability is fixed, we will publicly disclose it (with credit to you if desired)

## Security Best Practices

When using this extension:

1. **Keep it Updated**: Always use the latest version of the extension
2. **Review Permissions**: The extension requests specific permissions necessary for its functionality
3. **Privacy**: The extension does not collect or transmit personal data to third parties
4. **Source Review**: The source code is available for audit and review

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.6.x   | :white_check_mark: |
| < 3.6   | :x:                |

## Security Features

- **No External Data Collection**: The extension operates locally and does not send your data to external servers
- **Minimal Permissions**: Only requests permissions necessary for core functionality
- **Open Source**: Code is publicly available for security audits
- **Regular Updates**: Active maintenance and security updates

## Known Limitations

- This extension modifies Coursera web pages and may be affected by changes to Coursera's website structure
- The extension requires specific permissions to function on Coursera domains
- Users should be aware of Coursera's Terms of Service when using automation tools

## Disclaimer

This extension is provided as-is for educational and productivity purposes. Users are responsible for complying with Coursera's Terms of Service and academic integrity policies.
