# Changelog

All notable changes to the Coursera Automation Extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [3.6.4] - 2026-02-09

### Added
- SECURITY.md file for vulnerability reporting and security policies
- GitHub Actions CI/CD workflow for automated validation
- Feature request issue template
- Comprehensive troubleshooting guide in README
- Browser compatibility table
- FAQ section with common questions and answers
- Privacy & security documentation
- Development setup instructions in CONTRIBUTING.md
- Code standards and commit message guidelines
- CI status badge in README

### Changed
- Enhanced CONTRIBUTING.md with detailed contribution process
- Improved README structure with better organization
- Updated manifest.json version to match README

### Fixed
- Version consistency between manifest.json and README.md

## [3.6.3] - Previous Release

### Features
- Complete quizzes automatically
- Complete lectures
- Complete reading materials
- Complete ungraded plugins (dialogue)
- Complete discussions
- Generate shareable links
- Quiz automation with AI-generated answers
- Skip Video+ functionality
- Course backup feature

### Keyboard Shortcuts
- `Alt + W` or `Alt + B`: Toggle the Extension
- `Alt + Z` or `Ctrl + Shift + Z`: Refresh answers or navigate to next question
